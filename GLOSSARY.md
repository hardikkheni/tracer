# Tracer

Tracer provides an on-page console experience accessed through a floating launcher.

## Language

**Floating Launcher**:
The round, on-page entry point to the console panel.
_Avoid_: Widget, toolbar button

**Console Panel**:
Tracer's on-page log-viewing surface, distinct from the browser's native DevTools Console.
_Avoid_: Native console, DevTools window

**Captured Page Logs**:
Page-originated log records collected by Tracer, not the complete set of messages available in browser DevTools.
_Avoid_: All logs, DevTools history
