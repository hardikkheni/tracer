# Triage Labels

Map canonical triage roles to the strings used in this repo's issue tracker.

| Canonical role | Tracker string | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate |
| `needs-info` | `needs-info` | Waiting on reporter for information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role, use its tracker string in the issue's `Status:` line.

Edit the Tracker string column to change the vocabulary.
